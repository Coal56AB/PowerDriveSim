# Проверка светлой и тёмной темы

Палитра общая для Qt widgets и рисуемых схем/графиков. Переключатель находится
в меню «Вид»; настройка хранится отдельно от проекта в `ui.ini`.

Проверено на Windows Release / Qt 6.5.3:

- Полный CTest: 15/15 групп успешно.
- `dark_theme_editor_graphs_and_persistence`: запуск 2L, открытый график,
  A/B курсоры и легенда, переключение в обе стороны, диалог стиля кривой,
  повторный запуск с сохранённой настройкой. Сериализованный проект не меняется.
- Native Windows запуск теста при масштабах 100% и 200% завершился успешно.
- Визуально проверены снимки русского редактора, графика с курсорами и диалога
  настроек: фон, текст, сетка, провода, значки и выделение согласованы.

Проверка не включает отдельное оформление системного заголовка окна Windows.
