# Ключи и диоды

В свойствах S/D поле **Модель** выбирает идеальную или кусочно-линейную модель.
Идеальная модель остаётся значением по умолчанию, в том числе при загрузке старых
проектов. На схеме кусочно-линейный элемент отмечается подписью `PWL`.

Ток положителен от вывода p к n, напряжение равно u(p)−u(n). Диод: p — анод,
n — катод. Управляемый S проводит ток обоих знаков; gate=true означает замкнутое
состояние. Встроенного обратного/body-диода у S нет: нужный диод ставится отдельно.

| Модель | Уравнения |
|---|---|
| Идеальный S | Замкнут: v=0; разомкнут: i=0. |
| Идеальный D | Проводит: v=0, i≥0; заперт: i=0, v≤0. |
| Кусочно-линейный S | Замкнут: v=Ron·i; разомкнут: v=Roff·i. |
| Кусочно-линейный D | При v≤Vf: i=v/Roff. При v≥Vf: i=(v−Vf)/Ron+Vf/Roff. |

Сопротивления удовлетворяют 0 < Ron < Roff; Vf ≥ 0. Все параметры конечные.
Значения при включении PWL: Ron=10 mΩ, Roff=1 MΩ, для диода Vf=0.7 V.
Поля принимают SI-единицы, например `50mOhm`, `10MOhm`, `600mV`.
Vf — координата непрерывного излома ВАХ; ток в этой точке Vf/Roff.
Такой выбор сохраняет непрерывность между прямой ветвью и явной утечкой.
Для S параметр Vf не используется и не предлагается в свойствах.

Ron/Roff — параметры выбранной физической модели, а не скрытая помощь решателю.
Например, заряженный конденсатор за закрытым PWL-диодом постепенно разряжается
через Roff. Идеальный диод удерживает заряд, если других путей разряда нет.
PWL не добавляет снаббер, ёмкость перехода, задержку gate или паразитную индуктивность.

Для PWL-диода доступна опциональная [динамика накопленного заряда](diode-charge-model.md)
с обратным восстановлением. [Тиристор T](thyristor.md) имеет отдельное состояние
удержания и ток Ih. Отдельные семантики MOSFET/IGBT остаются следующей частью M2. Табличные переключательные и температурные потери не вычисляются.

## Исполнение и проверки

Обе модели используют общий MNA и тот же ограниченный active-set поиск состояния
диода. Излом в естественной коммутации определяется на концах шагов; заданные gate-
и source-события обрабатываются точно. Матрицы учитывают выбранный Ron/Roff,
топологическая диагностика различает идеальное ограничение и резистивный путь.
Числовые параметры PWL можно выставить публичными параметрами подсхемы.

Группа `semiconductors` проверяет:

- аналитические ВАХ, знаки тока и баланс мощности в обоих методах;
- отрицательное/положительное питание, область около Vf, утечку и параллельные диоды;
- коммутацию вне основной сетки и импульсное питание;
- аналитический заряд RC и обратный разряд через утечку; интегральный баланс энергии;
- параметры, ошибки, undo/redo, schema 8→9, round trip и иерархические overrides;
- независимость от порядка объектов и запуск freewheel/2L/NPC с PWL через generic solver.

Для RC (R=10 Ω, C=1 mF, Ron=0.2 Ω, Roff=1 kΩ, Vf=0.7 V, шаг 1 μs, время 10 ms)
максимальная ошибка заряда: BE 77.5274 μV, Trapezoidal 1.26685 nV. При разряде:
9.70637 nV и 8.65974e−15 V соответственно. Допуск интегрального баланса 0.6 μJ.
PWL-инверторы проходят с максимумом 1/3 итерации на решение для 2L/NPC;
это измерение поставляемых примеров, не обещание сходимости произвольной схемы.

Windows Release: 17/17 CTest. Нативный UI-тест выбирает обе модели, проверяет
поля/ошибки/undo, запускает схему, сохраняет и повторно открывает проект.
