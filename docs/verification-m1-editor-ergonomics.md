# Проверка управления редактором M1

Дата: 15 сентября 2026. Эта проверка касается взаимодействия плоского редактора; она не означает полной приёмки M1.

## Реализованное поведение

- Отменяемые жесты с предварительной геометрией и порогом начала перетаскивания; обработка потери захвата.
- Сохранение выделенной группы и существующих объектов сцены при правках. Перемещение внутренних контрольных точек вместе с группой.
- Предварительная вставка и поворот/отражение фрагментов; быстрый поиск на холсте по общему каталогу.
- Ответвление в обоих направлениях, ручки сегментов/изгибов/концов, атомарное переподключение, общий маршрут предпросмотра и результата.
- Попадание в порты/провода в экранных координатах, направляющие, Alt для свободного перемещения, автопрокрутка возле края.
- Enter/завершение ввода и Esc в свойствах, черновики по UUID, таблица событий, сохранение параметров запуска до пуска.
- Независимое состояние просмотра графиков, их собственные кнопки масштаба, перетаскивание времени/курсоров и секунды на осях.
- Сохранение результатов при геометрических правках; навигация холста во время worker Run/Stop.

Устройство модулей и команды воспроизведения: [editor-interaction.md](editor-interaction.md).

## Среда

Windows 10, Intel Core i5-14600KF, MSVC 19.44 (Visual Studio 2022), Release, Qt 6.5.3 MSVC 2019 x64. Зависимость Qt размещена в игнорируемом `.deps/qt` и не входит в исходники.

## Общие участки сетей и ускорение Reference CPU — 16 сентября 2026

Автоматические электрические провода используют уже проложенные участки той же сети, включая цепочки промежуточных узлов. Место ответвления отмечается точкой и пересчитывается при переносе. Заданные вручную маршруты служат опорными; чужие сети не объединяются, подключения выводов не меняются. В сохранённой пользовательской схеме резистор развёрнут на 180°: правый p подключён к левой сети, левый n — к правой. Этот перекрёстный порядок сохранён, поскольку его изменение меняет знак измеряемого тока. Отдельная визуальная проверка тестовой копии с обычной ориентацией подтверждает короткие ответвления с обеих сторон.

В solver добавлен ленивый ограниченный кеш систем по точному h, режиму начальных условий, gates и active set диодов. На повторных шагах обновляется только RHS; буферы и факторизация используются повторно. Вычисления с нулевыми коэффициентами исключены из подготовленной последовательности. Проверка невязки, конечности решения, неравенств диодов и bounded search сохранены. Поиск соседних active sets выделяет контейнеры только при нарушении текущего состояния. Большая предыдущая история освобождается вне UI-потока. Подробности и команды — в [описании производительности solver](solver-performance.md).

Измерения на этой машине, пользовательская freewheel-схема, Trapezoidal, PWM 10 Hz, шаг 1e-7:

GUI с полной историей, Scope и окном графика: 10 млн шагов — 3,76/3,84 с с дополнительным Fit/рендерингом; worker — 2,739/2,734 с, dispatch — 0/1 мс. Компиляция модели в отдельных замерах — около 0,17–0,18 мс; первый отсчёт — ещё около 0,02 мс. Это локальные результаты, не гарантия для всех моделей.

Промежуточный полный прогон 100 млн шагов (10 с при 1e-7) с генерацией всех выбранных отсчётов занял 28,694 с. Этот benchmark принимает и освобождает потоковые пакеты, не хранит всю историю и не рисует графики. Цель менее 5 с не достигнута. Запись и экспорт не прореживаются.

Проверки: 13/13 CTest (5,20 с). Оконный тест перемещения проверяет общую линию через промежуточный узел, отсутствие объединения разных сетей, undo/redo и сохранение. Сравнение со старым EXE: по 210004 отсчёта Backward Euler и Trapezoidal с переключениями — CSV побайтно одинаковы. Для 1000 элементов/950 проводов до добавления обхода промежуточных узлов p95 перемещения составлял 10,919 мс. EXE пересобран, пользовательская схема сохранена и восстановлена после копирования примеров сборкой.

Тёмная тема зафиксирована как отдельное невыполненное требование в AGENTS.md.

Финальная проверка после ограничения пересчёта затронутыми сетями: 13/13 CTest, 5,25 с; оконные routing/performance — 4 passed. Для 100/500/1000 элементов p95 перемещения — 1,284/4,785/15,444 мс. SHA-256 пользовательской схемы совпадает с резервной копией.
