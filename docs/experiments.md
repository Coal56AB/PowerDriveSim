# Серии расчётов и сценарии

Серия использует одну исходную схему и набор числовых изменений. Каждый
вариант запускается с собственным начальным состоянием через общий compiler
и Reference CPU. Исходный проект не меняется, предыдущее решение не становится
неявным начальным состоянием следующего.

## Модель серии

`Project::experiments` (schema 15) хранит:

- UUID и имя серии;
- оси перебора: путь экземпляров, UUID объекта, поле и список значений;
- именованные сценарии с несколькими числовыми переопределениями;
- записываемые каналы, диапазон измерений и флаг сохранения кривых.

Оси образуют декартово произведение. Последняя ось меняется быстрее;
для каждой комбинации последовательно запускаются все сценарии. Без сценариев
используется один базовый вариант, без осей — только заданные сценарии.
API создаёт линейные и логарифмические списки; логарифмический диапазон
требует положительных границ. Список может быть и задан явно.

Публичный параметр подсхемы разрешается по её bindings до атомарного поля.
Изменение применяется после flatten к UUID конкретного экземпляра.
Другие экземпляры общего определения сохраняют свои значения. Два изменения
одного атомарного поля, в том числе через разные публичные псевдонимы,
отклоняются как конфликт. Геометрия, строки и массивы не являются осями.
Логические поля принимают 0/1; перечисления — целочисленный индекс.

Пустой UUID объекта адресует числовой параметр профиля: `stop`, `step`,
`warmup`, допуски нелинейного решения, `minimum_step` или
`adaptive_relative_tolerance`. Путь экземпляров в этом случае пустой.

Серия ограничена 100000 вариантами, 64 осями и 100000 явно перечисленными
значениями/переопределениями. Варианты создаются по одному; старт не создаёт
массив из копий всех схем. Ошибка физической схемы сохраняется в строке
варианта и не прерывает остальные варианты. Stop проверяется между вариантами
и передаётся обычному исполнителю во время расчёта.

## Измерения

Для каждого выбранного канала сохраняются среднее, RMS, стандартное
отклонение и интеграл по времени, последний отсчёт, минимум и максимум
в выбранном интервале. Интерполяция совпадает с
[интегралами Scope](scope-integrals.md). Конец `-1` означает конец расчёта.
Диапазон, не пересекающий запись, оставляет измерения пустыми.

Без выбранных каналов история не записывается. При выключенном сохранении
кривых память результата освобождается после вычисления метрик каждого
варианта. При включённом флаге API передаёт также кривые потребителю;
размер серии в памяти зависит от политики этого потребителя.

## CLI

```powershell
build/Release/powerdrive-cli examples/rc-sweep.pds build/rc-sweep.csv --experiment "RC resistance"
```

Пример перебирает R = 500/1000/2000 Ом и два напряжения источника: 1 и 2 В.
CSV содержит параметры, статус, метрики каждого канала, число шагов,
модельное и фактическое время. Ошибочные варианты тоже присутствуют в таблице.
Имя серии можно заменить её UUID. Команда возвращает ненулевой код, если
хотя бы один вариант завершился ошибкой. CLI сохраняет сводку, а не все кривые.
Снимки состояния и пошаговый запуск не комбинируются с серией.

## Проверки

`experiments`: аналитика RC при разных R/V, порядок комбинаций,
ошибочные параметры, побитовая повторяемость, независимость вложенных
экземпляров, конфликт публичного/прямого параметра, сохранение проекта,
Stop и 1000 вариантов без записи. `experiments-cli` запускает поставляемый
пример и формирует сводный CSV.

## Оконный редактор

Команда «Расчёт → Серии расчётов…» открывает редактор сохранённых серий
проекта. В нём можно создать и удалить серию, изменить имя, интервал
измерений, флаг сохранения кривых, список каналов, оси перебора и сценарии.
Оси задаются строками `object field value...`; для параметров профиля вместо
UUID объекта используется `profile`. Вложенный путь экземпляров записывается
через `/`, например `instance/subinstance/object value 10`. Сценарии задаются
строками `name | object field value; object field value`.

Кнопка «Запустить серию» выполняет выбранную серию через общий исполнитель
`run_experiment` и показывает строки вариантов в окне. «Экспорт сводки CSV»
запускает ту же серию и записывает таблицу в том же формате, что CLI. Правки
серий сохраняются в `Project::experiments` через обычную историю документа.
