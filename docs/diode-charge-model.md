# Динамика заряда диода

Реализована опциональная динамика заряда PWL-диода в Reference CPU.
В свойствах выберите кусочно-линейную модель и **Заряд диода → С динамикой**.
По умолчанию Tm=1 μs, τ=5 μs, начальный заряд 0 C; поля принимают SI-единицы.
Готовая схема `examples/diode-recovery.pds` открывается из меню «Примеры»;
её график показывает входное напряжение и измеренный ток диода.

Основа: charge-control уравнения Lauritzen–Ma, приведённые в
[документации Diode MathWorks](https://www.mathworks.com/help/sps/ref/diode.html).
Используются время переноса Tm, время жизни τ и состояние накопленного заряда q.
Утечка Roff остаётся отдельной статической ветвью нашей непрерывной PWL-модели.

## Уравнения

Положительные направления: v=u(p)−u(n), i от p к n. Обозначим
G0=1/Roff, Gf=1/Ron−1/Roff, a=(τ+Tm)Gf, α=a/Tm, λ=1/Tm+1/τ,
x=max(v−Vf,0). Тогда:

```text
i = G0 v + α x − q/Tm
dq/dt = α x − λ q
```

В установившемся состоянии q=τGf x и i=G0v+Gf x: в точности статическая PWL-ВАХ.
При обратном напряжении заряд экспоненциально спадает с постоянной 1/λ,
создавая обратный ток −q/Tm дополнительно к утечке.

Tm>0, τ>0, q_initial≥0 задаются явно; динамика выключена по умолчанию.
При включении начальный заряд по умолчанию нулевой. Переключение gate/source
не сбрасывает q. Режим доступен только PWL-диоду; настройки сохраняются при
временном переключении на идеальную модель, где они не участвуют в расчёте.

## Дискретизация и MNA

Для BE m=h, B=q_previous. Для Trapezoidal m=h/2,
B=q_previous+m·qdot_previous. k=1/(1+mλ).

```text
q_new = k B + k m α x_new
i_new = G0 v_new + α k (1+m/τ) x_new − k B/Tm
```

Таким образом, после исключения q остаётся линейный stamp каждой ветви active-set,
с дополнительной history RHS. Динамика не требует предварительной сетки времён.
В алгебраическом решении при старте/событии q фиксирован: используется исходное
уравнение тока. Выбор ветви зависит от v относительно Vf, а не от знака полного тока.

Состояния обновляются только после сходимости. Отрицательный q вследствие слишком
крупного шага Trapezoidal приводит к адресной диагностике и предложению
уменьшить шаг/выбрать BE, без скрытого обнуления. Автоматический контроль шага
будет общим механизмом следующего блока M2.

## Энергия и проверки

Для этой модели запасённая энергия E=Vf·q+q²/(2a). При v>Vf потери сверх утечки
равны (Tm/a)·i_extra²+(Vf+q/a)·q/τ и неотрицательны; при v≤Vf:
(Vf+q/a−v)·q/Tm+(Vf+q/a)·q/τ. Утечка добавляет G0v².
Это позволяет отдельно проверять баланс энергии без подмены физики численным clamp.

Проверки `diode-charge`: DC-предел; накопление/экспоненциальный спад заряда;
обратный ток при ступени источника; сохранение заряда на событиях;
BE/Trapezoidal и сходимость по шагу; энерго-баланс; неверные параметры/крупный шаг;
generic преобразователь; schema/undo/flatten и свойства в GUI.

При Tm=1 μs, τ=5 μs, Ron=2 Ω, Roff=100 kΩ, Vf=0.7 V тест переключает источник
с +1 V на −2 V в 100 μs. Накопленный заряд перед фронтом 0.749985 μC;
обратный ток сразу после фронта −0.750005 A. При шаге 25/12.5 ns максимальная
ошибка заряда BE — 4.08739/2.05646 nC; Trapezoidal — 20.6938/5.17326 pC.
Невязка интегрального баланса энергии — менее 43 pJ.

Полный Windows Release: 18/18 CTest. Нативный UI-тест меняет временные параметры
и начальный заряд, переключает модель с сохранением настроек, делает undo/run/save/load.
Формат schema 10 хранит физические настройки; состояние выполненного расчёта пока
не сохраняется. Snapshot/continue остаётся отдельным следующим блоком M2.
