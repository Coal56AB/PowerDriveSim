# Проверка M1: настольный редактор

## Объём

Рабочий плоский редактор поверх общего ядра: библиотека R/L/C/V/I/S/D/VP/IP, земля, узлы, типизированные порты, явные провода, свойства, записанные gate patterns, Scope и фоновый расчёт. Это законченный блок M1, **не полная приёмка M1**.

GUI меняет `Document`; компилятор разрешает соединения в сети и строит независимый IR. Qt отсутствует в модели, компиляторе и решателе. Worker получает копию проекта; сообщения Qt и графический рендеринг выполняются в UI-потоке. Отмена и показ времени передаются через атомарные переменные.

## Проверки Windows, 15 сентября 2026

Release, MSVC 19.29, Qt 6.5.3. Все **11/11 групп CTest прошли**, последняя полная проверка — 3.82 s. Численные/регрессионные группы из предыдущего этапа сохранены.

Новая группа `desktop` использует настоящий Qt Widgets с `offscreen`:

- создание RC-цепи щелчками по библиотеке и холсту, соединение четырёх проводов щелчками по портам;
- редактирование сопротивления через Inspector, проверка SI parsing, undo/redo, отклонение ошибочного значения без изменения модели;
- запуск 5000 шагов из GUI, сравнение выходного напряжения с `1-exp(-5)` (ошибка меньше 2e-5 V);
- оба курсора, сохранение UUID/проводов/курсов, открытие и восстановление отдельной резервной копии;
- фоновый расчёт с периодической обработкой UI-таймера, запрос Stop на третьем тике, получение частичного результата в пределах 5 s;
- диагностика оборванной схемы и выделение её объекта по строке ошибки;
- удаление провода, undo/redo с сохранением UUID;
- записанные gate-события 1 ms/2 ms, запрет смешивания signal/gate, VP=1 V и IP=1 mA в нагрузке 1 kOhm;
- выбор u/i/gate каналов, zoom/fit, сохранение pattern/events/Scope.

Тест обнаружил и устранил обращение обработчика выделения к уже уничтоженному документу при закрытии окна. Состояние busy сохраняется до обработки завершения worker в UI-потоке, исключая применение результата к уже открытому новому проекту.

Снимок `docs/images/desktop-rc.png` получен из работающего окна после тестового расчёта и проверен визуально. Это не макет. Маршрутизация обходит простые символы; для сложных случаев доступны сохранённые ручные точки проводов.

Собран `build/Release/powerdrive-desktop.exe`; библиотеки Qt размещены рядом через windeployqt. Системный MSVC runtime отдельно не упакован; на машине разработки он уже установлен. Тексты интерфейса RU/EN включены в ресурсы приложения. Для стандартных диалогов используются средства Qt/ОС.

## Автоматическая проверка

Workflow собирает ядро без Qt и отдельно редактор с Qt 6.5.3 на Windows. UI-тесты не управляют рабочим столом. Статус конкретного опубликованного запуска фиксируется в AGENTS.md после завершения CI.

## Что ещё не принято

Полный M1 требует hierarchy/public ports/open internals/edit definition/detach/flatten, атомарных 2L VSI/3L NPC, их изменённых топологий и дополнительных проверок производительности и топологии. Они не подменены демонстрацией RC.

Текущие ограничения: общий Y-масштаб Scope, одна резервная копия на каталог приложения, выбранные результаты в RAM, Stop между шагами, простой автоматический маршрут проводов, отсутствие поворота/копирования элементов.


## Уточнения интерфейса и выборочная запись

Верхняя панель содержит время/шаг/метод перед «Пуск». Библиотека — дерево из пяти категорий. Узел создаётся через Ctrl+W или продолжение провода; отдельной позиции библиотеки нет. Выводы рисуются радиусом 2 px, невидимая область попадания — 14×14 px; при hover появляется мягкая подсветка.

Блоки графиков имеют 1–16 сигнальных входов, принимают VP/IP и gate patterns, открываются в независимых окнах и сохраняют свои курсоры. Электрические выводы не могут подключаться к сигнальным входам. Два графика могут использовать один сигнал без дублирования истории.

Scope по умолчанию выключен: виджет графика создаётся только при включении, история пишется только для подписок. Без графиков/подписок Result содержит 0 samples и нулевую capacity истории. Расчёт сохраняет те же шаги, конечное время и residual, что с полной записью. QFuture::takeResult переносит результат в UI без оставшейся второй копии; отключение Scope освобождает неиспользуемые графиками каналы.

Дополнительная группа recording проверяет отсутствие истории, выборочную запись, отдельные графики, точные события graph-only gate pattern, экспорт подмножества, migration v4→v5 и независимые настройки графиков. UI-тест проверяет два окна, освобождение Scope, запись ровно одного общего сигнала, отсутствие глобального Export и создание узлов Ctrl+W. desktop-launch проверяет настоящий entry point с автоматическим завершением.

Оформление пустого холста, свойств без выделения, диагностики, дерева библиотеки, графиков и табов результатов выполнено непосредственно в приложении. Снимки desktop-rc.png и desktop-plot.png получены из этих окон, без дорисовки.

## Проверка последних изменений редактора

Все 11 групп CTest прошли на Windows. Дополнительно проверены реальные press/move/release для подключения графика к середине провода, атомарная отмена ответвления, координаты вывода после поворота, отражение и копирование с новыми UUID. Постоянный ШИМ проверен на точных фронтах 0.0001 и 0.00035 с, сохранение параметров и ориентации — через roundtrip. Вставка проверяется двойным щелчком в библиотеке.
