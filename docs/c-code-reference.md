# Справочник безопасного C-кода

Один и тот же набор встроенных функций доступен в коде инициализации, Gate и
пользовательских блоках кода. Исполнение интерпретируется и ограничивается по
числу инструкций, глубине вызовов и размерам массивов.

В Gate доступны `t` и `stime` — текущее время моделирования. В блоке кода также
доступен `dt` — его период выполнения. Код инициализации запускается один раз;
зависящие от времени функции в нём вычисляются для `t = 0`.

## Функции времени

- `ramp(t0, t1, v0, v1)` — линейный переход от `v0` к `v1`, с ограничением на
  концах интервала.
- `pulse(start, duration)` — одиночный единичный импульс.
- `pwm(frequency, duty, delay)` — ШИМ после неотрицательной задержки; `duty`
  задаётся от 0 до 1. `square` является синонимом.
- `phasepwm(frequency, duty, phase)` — периодический ШИМ с циклическим фазовым
  сдвигом, который может быть отрицательным.
- `saw(frequency, delay)` — пила в диапазоне 0…1.
- `triangle(frequency, delay)` — треугольный сигнал в диапазоне −1…1.

## Обработка сигналов

- `clamp(x, low, high)` — ограничитель.
- `saturate(x)` — ограничитель диапазоном 0…1.
- `lerp(a, b, k)` — линейная интерполяция без ограничения `k`.
- `step(edge, x)` — 0 ниже порога и 1 на пороге и выше.
- `smoothstep(low, high, x)` — гладкий переход 0…1.
- `deadband(x, width)` — симметричная мёртвая зона с непрерывным выходом.
- `wrap(x, period)` — перенос значения в диапазон `[0, period)`.
- `sign(x)` — −1, 0 или 1.

## Математика

Доступны `abs`, `fabs`, `sqrt`, `sin`, `cos`, `tan`, `asin`, `acos`, `atan`,
`atan2`, `exp`, `log`, `log10`, `floor`, `ceil`, `round`, `pow`, `fmod`, `min`,
`fmin`, `max`, `fmax`, а также константы `PI` и `M_PI`.

Можно объявлять собственные функции, локальные переменные и сохраняемое между
вызовами состояние через `static`. Поддерживаются `if/else`, `for`, `while`,
`break`, `continue` и `return`.

Справочник открывается в программе через **Справка → Справочник по C-коду** или
клавишей **F1** внутри редактора. Поиск — **Ctrl+F**, замена — **Ctrl+H**,
форматирование — **Ctrl+Shift+F**.
