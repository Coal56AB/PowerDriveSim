# DC/DC: buck, boost и инвертирующий buck-boost

В категории «Преобразователи» доступны три раскрываемые силовые схемы.
Каждая содержит отдельные S, D, L, C и последовательное сопротивление
конденсатора ESR. Все соединения и модели можно редактировать внутри блока.

## Интерфейс

| Порт | Назначение |
|---|---|
| IN | Вход питания относительно COM |
| OUT | Выход относительно COM |
| COM | Общий электрический вывод, без встроенной земли |
| g | Внешняя логическая команда ключа S |

| Параметр | По умолчанию |
|---|---|
| L | 2 мГн |
| iL(0) | 0 А |
| C | 220 мкФ |
| uC(0) | 0 В |
| ESR | 50 мОм |

Параметры экземпляра меняются в свойствах без изменения общего определения.
`iL(0)` задаёт ток в направлении p→n внутренней индуктивности, `uC(0)` —
напряжение p−n внутреннего конденсатора. У инвертирующей схемы установившееся
напряжение OUT и напряжение конденсатора отрицательны относительно COM.

S и D по умолчанию идеальные. S — двунаправленный идеальный ключ, а не
скрытая модель MOSFET с body-диодом. Для другой полупроводниковой модели
измените атомы внутри определения. Частота, заполнение, питание и нагрузка
задаются внешними элементами; встроенного регулятора нет. ESR — видимый
физический компонент, его значение доступно в свойствах блока.

## Примеры и режим

`examples/buck.pds`, `boost.pds`, `buck-boost.pds`: питание 24 В,
PWM 10 кГц с заполнением 40%, нагрузка 20 Ом, время 50 мс, шаг 1 мкс.
График показывает выходное напряжение и ток нагрузки; оба сигнала имеют
отрицательный знак у инвертирующей схемы при выбранных направлениях измерений.

В непрерывном режиме тока индуктивности идеальные соотношения:

| Схема | Uout / Uin | Идеальный ориентир при D=0.4 | Среднее в примере, Trapezoidal |
|---|---|---|---|
| Buck | D | 9.6 В | 9.6003 В |
| Boost | 1/(1−D) | 40 В | 39.9242 В |
| Buck-boost | −D/(1−D) | −16 В | −15.9684 В |

Средние измерены за 40–50 мс. Отличие от идеального ориентира включает
пульсации и явный ESR. При малом токе нагрузки режим может стать прерывистым,
и приведённые соотношения перестают определять результат.

## Проверки

CTest `dcdc` проверяет оба метода, среднее напряжение, ток нагрузки,
комплементарность диода, мгновенный баланс мощности и накопленную энергию,
сохранение и выполнение после раскрытия блока.

Для проверки энергии используются независимые уравнения мощности источника,
нагрузки и ESR на каждом интервале постоянного gate. В Backward Euler отдельно
учитывается численное рассеяние `Σ(L·Δi² + C·Δu²)/2`. В Trapezoidal работа
вычисляется по средним состояниям интервала. Фронт PWM относится к следующему
интервалу, поэтому скачок тока источника не размазывается трапецией через фронт.
Допуск баланса для поставляемых схем — 1 мкДж; проверка не отключает начальный
переходный процесс.

Нативный UI-тест вставляет все три блока, меняет L с SI-единицами, отменяет
изменение, открывает внутреннюю схему, сохраняет и запускает пример.
Шаблоны — `library/converters`; генератор — `tools/generate_dcdc_library.py`.
