# Идеальный трансформатор

Четырёхвыводный атом `Transformer` имеет первичные выводы `p`, `n` и
вторичные `sp`, `sn`. Параметр `Np/Ns` задаёт отношение числа витков первичной
и вторичной обмоток. Направления напряжений: `p → n` и `sp → sn`.

Модель выполняет уравнения `Vp = (Np/Ns) · Vs` и
`Is = −(Np/Ns) · Ip`. Она сохраняет мгновенную мощность и гальванически
разделяет обмотки. Каждой изолированной части схемы нужен опорный узел.
В модели нет намагничивания, индуктивности рассеяния, сопротивления обмоток,
насыщения или потерь. Для этих эффектов нужны отдельные элементы либо будущая
неидеальная модель; результат идеального атома не следует считать моделью
реального сердечника.

Пример `examples/ideal-transformer.pds` даёт отношение 2:1, источник
10 V амплитуды при 50 Hz и нагрузку 8 Ω. На вторичной обмотке получается
5 V амплитуды, а источник видит сопротивление 32 Ω. Численный тест проверяет
напряжения, ток и баланс мощности на всей синусоиде; CLI проверяет чтение и
выполнение сохранённого примера. Формат проекта: schema 29, запись
`transformer_secondary` хранит вторичные узлы для схем без явных проводов.
