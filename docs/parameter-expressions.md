# Переменные схемы и выражения параметров

Schema 22 хранит в каждой схеме собственный код инициализации и выражения,
привязанные к числовым свойствам элементов. В GUI код открывается через
«Расчёт → Переменные и выражения…», а выражение вводится прямо вместо числа в
Inspector.

```c
const double udc = 540;
double load = 12;
double switching_frequency = 10e3;
```

После этого числовое поле может содержать, например, `udc / 2` или
`1 / switching_frequency`. Выражения используют внутренние единицы конкретного
свойства без текстовых суффиксов: электрические величины — SI, duty — 0…1,
поле фазы — градусы. Суффиксы `kOhm` и подобные остаются синтаксисом обычного
числового поля, но не частью языка выражений.

Область имён локальна для текущей схемы или определения подсхемы. Перед flatten
ядро разбирает переменные, проверяет неизвестные и циклические ссылки, вычисляет
каждую привязку и записывает результат в копию проекта. Исходный документ не
мутирует при компиляции. Ошибка имеет код `invalid_initialization` или
`invalid_parameter_expression` и UUID схемы/элемента.

Исходный многострочный UTF-8-код и тексты выражений сохраняются в `.pds` без
ссылок на внешние файлы. Undo/Redo охватывает изменение кода и полей. Удаление
элемента удаляет его привязки; копирование переносит их при совместимой области
переменных. При вставке в схему с другим кодом инициализации остаётся уже
вычисленное числовое значение, чтобы не создавать сломанную скрытую ссылку.

Этот механизм не имеет доступа к значениям узлов или токов во время шага и не
создаёт алгебраической обратной связи. Runtime API задержанных сигналов остаётся
отдельной последующей задачей.
