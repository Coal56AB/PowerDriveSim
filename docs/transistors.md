# MOSFET и IGBT

В категории «Ключи и диоды» доступны **MOSFET с body-диодом** и **IGBT с обратным
диодом**. Это редактируемые подсхемы. Двойной щелчок открывает канал и отдельный
диод; «Редактировать общее определение» разрешает менять общую схему. Для изменения
только выбранного экземпляра сначала используйте «Сделать независимую копию».

Внешние выводы MOSFET: D (сток), S (исток), G (логический gate).
Для IGBT: C (коллектор), E (эмиттер), G. Gate=true включает канал, false выключает;
начальный gate канала выключен. При внешнем подключении начальное значение и события
приходят из записанного сигнала/PWM. Удержания, как у тиристора, нет.

## Явная схема

| Блок | Канал | Отдельный обратный диод |
|---|---|---|
| MOSFET | S, проводит в обе стороны при gate=true | Анод S, катод D |
| IGBT | IGBT, прямая проводимость C→E только при gate=true | Анод E, катод C |

У открытого MOSFET обратный ток может идти через канал и body-диод одновременно;
доли токов следуют их ВАХ. У IGBT обратный силовой ток идёт через отдельный диод.
Удаление диода внутри подсхемы действительно удаляет этот путь.
Параметры/динамика диода редактируются независимо, включая обратное восстановление.

Атом **IGBT · Канал** доступен и отдельно. `p` — коллектор, `n` — эмиттер, `gate`
— логический вход. В идеальном режиме gate=true разрешает v=0, i≥0; иначе канал
заперт. В PWL при gate=true и v>Vf действует i=(v−Vf)/Ron+Vf/Roff;
во всех остальных состояниях i=v/Roff. Дополнительного обратного диода у атома нет.

Библиотечные блоки по умолчанию используют PWL: Ron=10 mΩ, Roff=1 MΩ,
Vf=0.7 V у диода и IGBT. Это параметры учебной модели, не паспорт конкретной детали.
Публичные параметры экземпляра: Ron/Roff канала, Vf IGBT, Ron/Roff/Vf диода.
Выбор идеального/PWL режима и начальное состояние доступны у атомов внутри блока.
Общие ограничения и допуски: [полупроводники](semiconductors.md).

Модели описывают переключение с логическим управлением, а не аналоговый gate-driver:
ёмкости затвора, плато Миллера, задержки и табличные переключательные потери здесь
не добавлены. Различие двунаправленного канала MOSFET и выпрямляющего канала IGBT
соответствует [MOSFET switching model](https://www.mathworks.com/help/sps/ref/mosfetidealswitching.html)
и [IGBT switching model](https://www.mathworks.com/help/sps/ref/igbtidealswitching.html).

## Библиотека и формат

Физические определения находятся в `library/semiconductors/*.pds`. В каждом файле
один размещаемый экземпляр и каталог его определений. Вставка копирует их в проект,
поэтому сохранённая схема работает без исходного библиотечного файла.
Если одноимённое определение с тем же UUID уже изменено пользователем, новая вставка
получает отдельное определение и сохраняет сделанные изменения.

JSON в `apps/desktop/components` содержит пункт палитры и поле `template` с путём
относительно `library/`. Программа сначала читает поставляемый файл рядом с EXE,
при его отсутствии — встроенный ресурс. Предпросмотр, перенос, поворот и отмена
используют обычный механизм вставки фрагмента; отдельного численного пути нет.
Шаблоны для разработчика генерируются `tools/generate_semiconductor_library.py`.
Python при работе приложения не требуется.

Schema 12 добавляет только новый атом `IGBT`; параметры берутся из существующей
записи `semiconductor`. Его `value`/`initial` равны нулю, `closed` задаёт начальный
gate. MOSFET состоит из прежних S/D и использует обычную иерархию.

## Проверки

Группа `transistors`: аналитическая ВАХ IGBT при обоих gate и знаках напряжения,
область около Vf, мгновенное выключение, off-grid события, баланс мощности,
оба метода, стабильность порядка UUID, сохранение и gate через публичный порт.
Для готовых MOSFET/IGBT проверяются оба режима, оба знака напряжения, нагрузки
10 Ω/10 mΩ, обратный путь и совместная проводимость канала/body-диода. Результат
сравнивается с аналитическим решением параллельных ВАХ и после раскрытия подсхемы.
Вставка, конфликт определений и undo сохраняют исходную схему.

UI-сценарий вставляет оба блока из библиотеки, редактирует отдельный диод,
подключает питание, нагрузку, gate и график, выполняет расчёт и сохраняет проект.

Windows Release: 20/20 CTest (14.14 s); отдельная конфигурация без Qt —
17/17 (4.37 s). Нативный UI-сценарий прошёл; снимки обоих блоков и их внутренней
схемы проверены. Повторные вставки получают различные имена экземпляров.
