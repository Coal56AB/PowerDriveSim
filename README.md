# PowerDriveSim

Симулятор силовой электроники, преобразователей и электроприводов. Проект создаётся для сборки электрических схем из отдельных компонентов, моделирования переключений и анализа токов, напряжений и переходных процессов.

Главная идея — открытая структура схемы: готовый преобразователь можно будет раскрыть до отдельных ключей, диодов, снабберов и соединений, изменить его и снова запустить расчёт.

## Текущее состояние

Разработан и проверен первый прототип численного ядра. Он рассчитывает цепи с резисторами, конденсаторами, индуктивностями, источниками и идеальными ключами. Начата разработка следующего этапа — атомарного редактора и коммутационных моделей.

**Графический редактор и установщик пока не выпущены.** Сейчас примеры запускаются из командной строки.

## Что уже работает

- расчёт произвольных поддерживаемых схем из отдельных R, L, C, источников напряжения и тока, идеальных ключей;
- два метода расчёта переходных процессов — Backward Euler и Trapezoidal;
- заданные начальные напряжения конденсаторов и токи индуктивностей;
- переключения ключей в заданные моменты, включая одновременные события;
- сохранение схемы, параметров, координат компонентов и настроек расчёта;
- загрузка проектов предыдущей версии;
- экспорт напряжений, токов ветвей и состояний ключей в CSV;
- диагностика ошибок схемы и численно вырожденных систем;
- автоматические проверки точности, повторяемости и готовых примеров.

## Особенности проекта

**Редактируемые преобразователи.** В целевом редакторе силовой блок будет обычной иерархической схемой с доступом к каждому внутреннему элементу.

**Универсальный расчёт.** Изменение поддерживаемой топологии не должно требовать отдельного решателя или правок исходного кода приложения.

**Прозрачная физическая модель.** Численные стабилизаторы не добавляются скрыто. Ошибочная схема получает диагностику.

**Отдельное управление и силовая часть.** Инвертор реагирует на готовые сигналы ключей. Будущий Controller с АЦП и алгоритмами управления относится к отдельному позднему этапу.

## Установка и запуск

Пока доступна сборка из исходников. Нужны CMake 3.20 или новее и компилятор с поддержкой C++20.

```sh
git clone https://github.com/Coal56AB/PowerDriveSim.git
cd PowerDriveSim
cmake -S . -B build
cmake --build build --config Release
```

Запуск примера в Windows:

```sh
build/Release/powerdrive-cli examples/rc.pds build/rc.csv
```

В Linux при обычной одноконфигурационной сборке приложение находится в `build/powerdrive-cli`. Результат примера сохраняется в `build/rc.csv`.

## Дальнейшее развитие

Ближайший этап — визуальный редактор, диоды, иерархические подсхемы, осциллограф и полностью редактируемые примеры инверторов 2L VSI и 3L NPC. Далее запланированы библиотека преобразователей, электрические машины, механические нагрузки и ускорение расчётов.
